# Word Format Checker

> ⚠️ **重要提示：本工具结果仅供辅助复核，不能替代人工审校；正式投标 / 正式提交前，请务必逐项人工复查，以免因漏检、误判或模板差异影响最终结果。**

面向 **河北省公共资源投标技术标 / 暗标格式检查** 的 Word `.docx` 检查工具。  
基于 **Streamlit + python-docx**，当前定位为 **v0.9**，核心目标是：**尽可能提前发现可能导致废标、扣分或不合规的格式问题。**

**关键词：** 暗标格式检查工具、技术标格式检查工具、招投标格式检查、河北暗标、Word 格式检查、docx 格式检查、bid document checker、tender document format checker。

## 这个工具是做什么的
这个项目不是在线 Word 编辑器，也不是为了追求高保真页面预览，而是一个：

> **严格规则检测器 + 标记副本辅助定位工具**

它更关注：
- 严格
- 不漏
- 可定位
- 可复核
- 便于回到本地 Word 中修改

而不是：
- 花哨 UI
- 在线编辑体验
- 复杂协同

## 当前能力

### 1）页面 / 结构检查
- 纸张尺寸检查（如 A4）
- 四边页边距检查（按 **cm → twips** 严格校验）
- 页数上限估算检查
- 手动分页符检查
- 分节符检查
- 目录 / 封面联合判定增强
- 页眉文字检查
- 页码字段检查

### 2）正文检查
- 字体检查
- 字号检查（中文字号 / pt）
- 固定行距检查
- 首行缩进检查
- 段前 / 段后间距检查
- 左对齐检查
- 段首空格检查
- 任意空格检查（含半角 / 全角空格）
- 禁用字符检查
- 加粗 / 斜体 / 下划线 / 颜色检查

### 3）表格检查
- 表格整体对齐
- 表格边框
- 跨页断行规则
- 单元格水平对齐
- 单元格垂直对齐
- 表内首行缩进
- 表内文字字体 / 字号 / 样式检查

### 4）对象与暗标合规检查
- 浮动对象检查
- 图片段落对齐检查
- 疑似“表格转图片”提示
- 手机号识别
- 邮箱识别
- 身份证号识别
- 银行信息识别
- 供应商 / 联系人 / 法定代表人 / 统一社会信用代码等敏感语义词识别
- 支持同段多命中，不只报首个

### 5）交互与定位能力
- 浏览器上传 `.docx`
- 点击按钮后再开始检查
- 生成标记副本
- 问题列表与标记副本通过 `【问题#N】` 编号映射
- 页面支持“合并展示”，减轻阅读负担
- 自动清理日志 / 缓存 / 临时目录

## 处理级别说明
默认业务口径：
- **格式类问题**：按 **必改** 处理
- **供应商身份 / 暗标信息识别类问题**：按 **警告 / 建议复核** 处理

页面中通常会同时保留：
- 原始级别（error / warn / info）
- 处理级别（必改 / 警告）

## 重要提示 / 使用须知
1. **本工具属于辅助检查工具，不构成法律、招标合规或废标结果的最终认定依据。**
2. **本工具会尽量从严检测，但不能保证 100% 无漏检、无误判。**
3. 对于复杂样式继承、主题字体、特殊分页、分节、嵌套对象、非常规模板等情况，仍可能存在边界误差。
4. 页数为**估算值**，不等同于 Microsoft Word 最终排版后的绝对页数。
5. 页码定位**不是主要定位方式**；请优先依据：
   - 页面问题列表
   - 问题编号范围 / 原始编号明细
   - 标记副本中的 `【问题#N】`
6. **标记副本不是最终修订稿。** 最终修改建议仍应在本地 Word 原文件中完成。
7. 对于正式提交文件，**强烈建议在提交前进行人工复核**，不要仅依赖本工具自动结果。

## 快速启动

```bash
git clone https://github.com/hjbjltnc/word-format-checker.git
cd word-format-checker
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

访问：
- 本机：`http://127.0.0.1:8501`
- 局域网 / 远程：`http://<server-ip>:8501`

## 推荐使用流程
1. 打开页面
2. 上传 `.docx` 文件
3. 点击“开始检查”
4. 查看问题列表
5. 下载并打开标记副本
6. 根据 `【问题#N】` 回到本地 Word 原文中逐项修改
7. 修改后重新上传复检
