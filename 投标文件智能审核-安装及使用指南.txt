投标文件智能审核
安装及使用指南

一、软件用途

本软件用于辅助审核投标文件，主要支持：
1. 审核商务投标文件；
2. 检查 DOCX 技术暗标格式；
3. 比对多份技术暗标文件中的重复内容；
4. 输出 Markdown（.md）格式审核结果，并在软件内预览。

重要提示：本软件结果仅供辅助复核，不作为最终评审结论、法律意见或废标依据。正式提交前请人工复核原始文件。

二、安装前准备

1. 电脑系统
   建议使用 Windows 10 / Windows 11 64 位系统。

2. 网络
   使用大模型审核时，电脑需要能访问所配置的大模型服务。

3. Python 环境
   只有“技术暗标格式检查”需要 Python。
   如未安装 Python，可在软件右上角点击“环境设置”，再点击“打开安装脚本”，按提示完成安装。

三、安装软件

1. 双击安装包：

   投标文件智能审核_0.1.0_x64-setup.exe

2. 按安装向导完成安装。
3. 如提示安装 Microsoft Edge WebView2 Runtime，请允许安装。
4. 从桌面或开始菜单启动“投标文件智能审核”。

四、技术暗标环境设置

如需检查技术暗标，请先确认右上角“环境设置”旁边为绿色状态。

如果显示“环境未就绪”：
1. 点击右上角“环境设置”；
2. 点击“打开安装脚本”；
3. 在弹出的命令窗口中等待安装完成；
4. 回到软件，点击“重新检测”；
5. 显示“环境已就绪”后即可使用技术暗标检查。

说明：
1. 安装脚本会自动检测 Python；
2. 未安装 Python 时，会自动下载并安装 Python；
3. 执行脚本时需要联网；
4. 如果单位电脑限制联网，请联系管理员协助安装 Python 及依赖。

============================================================
【重点】DeepSeek API 获取与配置
============================================================

本软件默认推荐使用 DeepSeek：

服务地址：https://api.deepseek.com
模型名称：deepseek-v4-flash

获取 API Key 步骤：
1. 打开 DeepSeek 开放平台：

   https://platform.deepseek.com

2. 注册或登录账号。
3. 进入 API Keys 页面。
4. 创建新的 API Key。
5. 复制 API Key，并妥善保存。
6. 回到本软件，点击右上角“API 设置”。
7. 选择 DeepSeek，粘贴 API Key。
8. 点击“测试连接”。
9. 测试成功后点击“保存设置”。

注意：
1. API Key 相当于账号密码，请勿公开或发给无关人员。
2. 建议勾选“保存到本机”，下次打开软件无需重复填写。
3. 如需清除密钥，可点击“清除当前密钥”。
4. DeepSeek 官方 API 文档：

   https://api-docs.deepseek.com

============================================================
【重点】每次审核大概费用
============================================================

费用取决于文件页数、文字量、投标文件数量、模型输出长度。

按 DeepSeek 官方 2026 年 7 月价格估算：
deepseek-v4-flash：
输入约 1 元 / 100 万 token（缓存未命中）
输入约 0.02 元 / 100 万 token（缓存命中）
输出约 2 元 / 100 万 token

常见消耗估算：

1. 小型任务
   1 份招标文件 + 1 份投标文件
   约 0.2 元 - 0.8 元人民币

2. 常规任务
   1 份招标文件 + 2 至 3 份投标文件
   约 0.8 元 - 3 元人民币

3. 较大任务
   1 份招标文件 + 4 份投标文件 + 4 份技术暗标
   约 2 元 - 8 元人民币

说明：
1. 以上为粗略估算，实际以 DeepSeek 账户扣费为准。
2. 文件越长、投标文件越多，费用越高。
3. 扫描件、重复测试、反复审核会增加消耗。
4. DeepSeek 价格可能调整，请以官方价格页为准：

   https://api-docs.deepseek.com/quick_start/pricing/

五、添加文件

1. 招标文件
   每次选择 1 份，支持 PDF / DOCX。

2. 商务投标文件
   每次可添加 1 至 4 份，支持 PDF / DOCX。

3. 技术暗标文件
   可为每份投标文件关联 1 份技术暗标。
   技术暗标格式检查仅支持 DOCX。

4. 扫描件
   如 PDF 是图片扫描件，可能无法提取文字。建议先 OCR 后再使用。

六、审核步骤

1. 添加招标文件。
2. 添加商务投标文件。
3. 如需检查暗标，给对应投标文件关联 DOCX 技术暗标。
4. 确认右上角显示“模型已配置”。
5. 如需暗标检查，确认右上角显示“环境已就绪”。
6. 点击“开始预检”。
7. 显示“准备完成”后，点击“开始审核”。
8. 等待审核完成。
9. 在“结果列表”中点击文件名，可在下方预览结果。
10. 点击“打开结果目录”，可查看全部 .md 结果文件。

七、结果文件说明

审核完成后，通常会生成：

01-商务审核-投标文件1.md
02-商务审核-投标文件2.md
101-技术暗标-投标文件1.md
102-技术暗标-投标文件2.md
90-技术文件比对.md

说明：
1. 文件数量会随实际上传文件变化；
2. 软件不再输出 PDF；
3. 最终结果均为 Markdown（.md）文件；
4. 可用记事本、Typora、VS Code、WPS 等工具打开。

八、结果怎么看

1. 商务审核结果
   重点查看“缺失、风险、需人工复核”等内容。

2. 技术暗标结果
   重点查看页面、页眉页脚、字体、段落、表格、图片、疑似身份信息等问题。

3. 技术文件比对结果
   只比对已关联的技术暗标文件。
   结果用于提示重复片段位置，需人工判断是否属于模板内容或异常重复。

九、常见问题

1. 提示“模型服务连接失败”
   检查网络、API Key、服务地址、模型名称和 DeepSeek 账户余额。

2. 提示“环境未就绪”
   点击右上角“环境设置”，运行安装脚本后重新检测。

3. 技术暗标检查被跳过
   请确认技术暗标文件是 DOCX 格式。

4. 预检失败
   请确认文件未加密、未损坏，并且不是纯图片扫描件。

5. 打不开结果目录
   请先确认审核已完成；也可在软件内重新点击“打开结果目录”。

十、数据安全说明

1. 原始文件和审核结果保存在本机。
2. 使用远程大模型时，软件会把提取后的文本发送给所配置的模型服务。
3. API Key 不会写入审核结果。
4. 请按本单位数据安全要求确认是否允许使用外部大模型服务。
