# 投标文件智能审核

这是一个本地优先的 Windows 审核工具基础工程。用户可选择一份可提取文本的 PDF/DOCX 招标文件，以及最多四份 PDF/DOCX 投标文件；每份投标文件可选关联一份 DOCX 技术暗标。

当前已实现本地预检、模型审核、投标文件文本查重、技术暗标辅助检查和 Markdown 汇总输出。任务会验证文件格式、可读性与文本可提取性，建立可恢复任务清单，并在界面显示每个已准备文件的文本块数量和最终审核结果预览。模型 API 设置保存在本机，密钥仅进入系统凭据管理器或进程内临时内存。

界面中的“准备完成”只表示预检已通过；点击“开始审核”后才会生成 `审核汇总.md`。

## 开发与 Windows 交付

开发和 Windows NSIS 打包步骤、依赖项及验收门禁见 [Windows 构建说明](docs/windows-build.md)。首版仅构建 NSIS 安装程序。

原始文件和本地处理结果不会上传；后续模型审核阶段仅会向用户配置的 HTTPS 模型 API 发送提取文本。用户本地模型的 `localhost` 或 `127.0.0.1` HTTP 地址也受支持。
