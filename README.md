# 📋 投标文件智能审核

一款辅助审核投标文件的桌面工具，用大模型帮你快速发现商务标、技术暗标中的问题。

> ⚠️ **重要提示**：审核结果仅供辅助复核，不作为最终评审结论、法律意见或废标依据。正式提交前请人工复核原始文件。

---

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 🧾 **商务标审核** | 对照招标文件，逐份检查商务投标文件的符合性 |
| 🔍 **技术暗标格式检查** | 检查 DOCX 暗标中的页眉页脚、字体、段落、表格、疑似身份信息等格式问题 |
| 🔁 **重复内容比对** | 比对多份技术暗标文件，提示重复片段位置 |
| 📄 **Markdown 结果** | 审核结果输出为 .md 文件，软件内可直接预览 |

## 🚀 快速开始

### 1️⃣ 安装软件

- 下载安装包 `TenderReview_Setup_0.1.0_x64.exe`，双击运行
- 按向导完成安装（如提示安装 Microsoft Edge WebView2 Runtime，请允许）
- 从桌面或开始菜单启动 **投标文件智能审核**

> 💻 建议系统：Windows 10 / 11 64 位

### 2️⃣ 配置大模型（DeepSeek）

审核功能依赖大模型 API，推荐使用 DeepSeek：

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，注册并登录
2. 进入 **API Keys** 页面，创建并复制 API Key
3. 打开软件，点击右上角 **「API 设置」**
4. 选择 DeepSeek，粘贴 API Key → 点击 **「测试连接」** → **「保存设置」**

> 🔐 API Key 相当于账号密码，请勿公开。建议勾选「保存到本机」，下次无需重复填写。

### 3️⃣ 技术暗标环境（可选）

仅**技术暗标格式检查**需要 Python。确认右上角「环境设置」为绿色 **环境已就绪**：

- 若显示「环境未就绪」：点击 **环境设置 → 打开安装脚本**，等待安装完成后点 **重新检测**
- 脚本会自动检测/安装 Python，全程需联网；单位网络受限时请联系管理员协助

## 📝 使用流程

1. **添加招标文件**（1 份，PDF / DOCX）
2. **添加商务投标文件**（1-4 份，PDF / DOCX）
3. （可选）为投标文件**关联 DOCX 技术暗标**
4. 确认右上角显示 **模型已配置**（如需暗标检查，还需 **环境已就绪**）
5. 点击 **「开始预检」** → 准备完成后点 **「开始审核」**
6. 在结果列表点击文件名预览，或点 **「打开结果目录」** 查看全部 .md 文件

> 📌 扫描件 PDF 可能无法提取文字，建议先 OCR 再使用。

## 📂 审核结果怎么看

| 结果文件 | 重点内容 |
|----------|----------|
| `01-商务审核-投标文件1.md` | 缺失项、风险点、需人工复核项 |
| `101-技术暗标-投标文件1.md` | 页面 / 页眉页脚 / 字体 / 表格 / 疑似身份信息 |
| `90-技术文件比对.md` | 重复片段位置（需人工判断是否属模板内容） |

结果文件为 Markdown 格式，可用 Typora、VS Code、WPS 等打开。

## ❓ 常见问题

| 问题 | 解决办法 |
|------|----------|
| 提示「模型服务连接失败」 | 检查网络、API Key、服务地址、模型名称及 DeepSeek 余额 |
| 提示「环境未就绪」 | 运行安装脚本后重新检测 |
| 技术暗标检查被跳过 | 确认暗标文件为 DOCX 格式 |
| 预检失败 | 确认文件未加密、未损坏、非纯图片扫描件、单文件超100MB |

## 🔒 数据安全

- 原始文件与审核结果**仅保存在本机**
- 使用远程大模型时，软件会把提取后的文本发送给所配置的模型服务
- API Key 不会写入审核结果
- 请按本单位数据安全要求，确认是否允许使用外部大模型服务
